# Qoder智能体平台

这是一个基于Qoder构建的智能体开发和演示平台。

## 项目结构

```
res/
├── qqq/           #资源文件夹
│   ├── *.gif      # 操作演示动图
│  └── ...        #其演示资源
├── .gitignore     # Git忽略配置
└── LICENSE        # 开源许可证
```

##功能特性

- **智能体管理**:支持Agent定义和编排
- **技能管理**: 提供Skill开发和注册功能  
- **演示资源**:包含丰富的操作演示GIF

##快开始

1.克仓库:
   ```bash
   git clone https://github.com/kkn1n/res.git
   ```

2.浏演示资源:
   ```bash
   cd res/qqq
   ```
